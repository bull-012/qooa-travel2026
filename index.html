😷 今年はヘイズ（煙害）が深刻です — N95マスクを必ず持参

2026年は 2015年以来の強いエルニーニョで乾季が長引き、インドネシアの野焼きの煙がマレーシア全土に流れ込んでいます。 8/28 時点でペナン（Minden 159 / Seberang Perai 158）も KL（Cheras 160）も API「不健康」水準。 専門家は、風向きが変わる10月頃まで続く可能性があるとしており、9/6〜9/11 の滞在は影響を受ける前提で準備してください。

  • 普通のマスクでは PM2.5 を防げません。N95 / KN95 / KF94 を人数分。
  • 目薬・のど飴・点鼻薬があると楽になります。呼吸器に持病がある人は普段の薬を多めに。
  • 現地の空気の状況は IQAir や APIMS（マレーシア環境局）で毎日チェック。
  • API 150 超えの日は屋外の長時間活動を避け、合宿・食事を屋内寄りに。宿ではエアコンの外気導入をオフに。

詳細は「現地情報」タブへ。数値は日ごとに大きく動くので、直前にもう一度確認してください。

共通の手荷物ルール

  • 受託手荷物 20kg（全員分あり）— 預ける荷物。個数の指定はなく合計 20kg まで。
  • 機内持ち込みは「2個まで・合計 7kg」
    ① メインの手荷物：56 × 36 × 23 cm 以内（機内の頭上収納に入るサイズ）
    ② 小物のパーソナルアイテム：40 × 30 × 10 cm 以内（ノートPCのバッグ、ハンドバッグ、小さめのリュックなど。座席の下に入るもの）
  • チューンプロテクトの旅行保険バンドル付き（往路）
  • フライト変更手数料無料枠（Zero Change Fee）付き
7kg は2個の合計です。AirAsia は搭乗ゲートで重さを実際に量ることがあり、超えると受託手荷物扱いで課金されます。 ②は「厚さ 10cm 以内」がかなり厳しいので、リュックをパンパンに詰めると①扱いになります。重いもの（PC・カメラ・本）は身につけるか①に寄せるのが安全です。

⚠️ KUL 乗り継ぎ 85分について（要確認）

往路の KUL 乗継は 06:15 着 → 07:40 発の 85分です。AirAsia が公表している klia2 での Fly-Thru 最低乗継時間は 90分とされており、公称値をわずかに下回ります。

  • 1つの予約として発券されているので、乗り遅れても AirAsia 側の振替対象になります（自己手配の別予約なら自己責任ですが、今回は該当しません）。
  • ただし当日は確実に急ぐことになるので、D7 523 の座席はなるべく前方に、降機したらすぐ「Domestic Transfer」へ向かうこと。
  • 手荷物は機内持ち込みだけで動ける状態にしておくとスムーズです。
  • 出発前にやること：AirAsia MOVE アプリで、この乗継が「Fly-Thru」扱いになっているか、ペナンまでの通し搭乗券が出るかを確認。出るなら KUL でのチェックイン作業は不要です。
もし KUL で乗り継げなかった場合も、ペナン行きは1〜2時間おきに便があります。慌てず AirAsia のカウンターへ。 その場合はランチの 12:00 に間に合わない可能性があるので、LINE で共有を。
予約番号・eチケットは LINE のノート／個別共有で確認してください。このページには載せていません。 AirAsia MOVE アプリに予約番号を入れておくと、当日の搭乗券表示がラクです。

🚢🚆 9/8(火) ペナン → KL の移動

ジョージタウンから フェリー で海峡を渡り、バターワース駅から ETS（電車） でクアラルンプールへ。所要は乗り継ぎ込みで約5時間です。

① フェリー：ジョージタウン → バターワース

  • 区間：Pangkalan Raja Tun Uda（PRTU／ジョージタウン側） → Pangkalan Sultan Abdul Halim（PSAH／バターワース側）
  • 運賃：大人 RM2（約70円）
  • 所要：約20分
  • 運航：バターワース発 6:30〜／ジョージタウン発 〜23:30、30分間隔（平日ラッシュ時は20分間隔）
  • 予約不要（乗車24時間前からのオンライン確保も可）
  • PRTU はジョージタウン中心部・Komtar から徒歩圏。Grab でも数分。
  • バターワース側は屋根付き通路で Butterworth 駅／Penang Sentral に直結、徒歩数分。
券売所は現金不可です。クレジットカードまたは電子ウォレット（Touch 'n Go 等）のみ。 カードが使えるメンバーが立て替える前提で動くと安全。

③ チケットの取り方

  • 公式（推奨・最安）：KTMB の KITS オンライン予約 または「KTMB MOBILE」アプリ
  • 代理店：Easybook / BusOnlineTicket（手数料上乗せあり、日本のカードが通りやすい）
  • テーブル席を狙う — ETS には座席が向かい合わせになったテーブル付きのボックス席があります。6人で固まって話せるので、座席選択の画面でここを押さえたいところ。人気なので早く予約するほど取れる確率が上がります。
  • 発売は乗車30日前から。→ 9/8 分はすでに発売中。
  • 運賃は Flexi Fare（変動制）。上表は目安で、直前ほど高くなります。
  • 駅名の表記は Butterworth → KL Sentral。
  • 大型スーツケースは持ち込めます（車両の端に荷物置き場あり）。ただし早い者勝ちなので、乗車は早めに。
  • 車内は冷房が強いので上着必須。3.5時間あるので飲み物と軽食を買っておくと快適です。
  • 酔い止めを持っていきましょう。テーブル席は半分が進行方向と逆向きになるうえ、3.5時間と長いので、酔いやすい人はきつくなる可能性があります。逆向きが苦手な人が先に順方向側に座れるよう、乗る前に確認を。
最優先の行動項目：5〜6名分の座席をまとめて、できればテーブル席で確保する必要があります。（日本発の5名＋岩永さんが同行するなら6名） テーブル席は数が限られるので、埋まる前に押さえたいところです。 バラバラの席にならないよう、できるだけ早く（できれば今日中に）公式サイトで押さえましょう。

もし取れなかったら（代替案）

  • Grab / タクシーで直行：ジョージタウン → ペナン大橋経由 → Butterworth 駅（フェリーを省略）。荷物が多い場合はこちらの方がラク。
  • 長距離バス：Penang Sentral → KL（TBS）。所要5〜6時間、RM35〜50程度。本数が多く当日でも取りやすい。
  • 飛行機：PEN → KUL（AirAsia が1日多数）。所要1時間だが空港移動を含めると時間差は小さい。

ℹ️ 現地情報

通信（重要）

  • eSIM は全員分すでに購入済み：Celcom / DiGi、5日間データ無制限。出発前にプロファイルを入れておくと現地で即使えます（アクティベートは現地到着後）。
  • ahamo 勢：海外ローミングがそのまま使える想定（月20GBまで／設定でローミングON）。
  • 電話番号を持っているのは2人だけ（ahamo 勢と現地在住の岩永さん）。eSIM はデータ通信専用のため、Grab の配車・電話認証・お店への電話はこの2回線に集約されます。はぐれた時の連絡先もこの2人。
  • トラブル時（繋がらない・データ切れ等）：ペナン空港／KLIA の到着ロビーにSIMカウンターがあるので、その場で購入できます（パスポート必要）。
  • Airbnb・カフェ・モールは Wi-Fi あり。連絡は LINE でつながるので、いざという時も慌てずに。

お金

  • 通貨：リンギット（RM / MYR）。RM1 ≒ 39円（2026年8月時点。ここ1ヶ月は 38〜40円で推移）。ざっくり RM × 4 − 1割 で暗算できます。
  • 目安：ホーカーの一皿 RM8〜15（約320〜590円）、カフェ RM15〜25、Grab 市内移動 RM10〜25。
  • チップの習慣は基本なし。レストランでは「Service Charge 10% + SST 8%」が伝票に乗ることが多いです。
  • 都市部のレストラン・モールはカード可。ホーカー・屋台・小さい店は現金のみ。
  • フェリーの券売所は逆に現金不可（カード／eウォレットのみ）。
  • 両替は空港より市中（ジョージタウンや KL の両替所）の方がレートが良いのが定番。
  • そこまで神経質にならなくてOK：岩永さんが現地の銀行口座を持っているので、現金が足りなくなっても立て替え・調達ができます。空港で少額だけ替えておいて、あとは市中かカードで回す形で問題ありません。
  • 精算は旅の後にまとめて。立て替えた人はレシート／メモを残しておきましょう。

移動

  • Grab が基本。流しのタクシーより安全・明朗会計。6人なら2台に分乗。配車は電話番号のある2人が担当（ドライバーからの着信に出られるため）。
  • KL 市内は LRT / MRT / モノレールが便利。Touch 'n Go カードがあるとスムーズ。
  • KL Sentral ⇄ KLIA は KLIA Ekspres で約33分（RM55前後）。

ヘイズ（煙害・大気汚染）

インドネシアのスマトラ島・カリマンタン島で行われる野焼きの煙が、南西モンスーンに乗ってマレーシアに流れ込む現象です。例年8〜10月に集中しますが、2026年は 2015年以来の強いエルニーニョで乾季が長期化し、火が消えにくくなっているため、ここ数年で最も深刻な年になっています。

  • API（大気汚染指数）の見方：0〜50 良好／51〜100 中程度／101〜200 不健康／201〜300 非常に不健康／301〜 危険。200 超で学校閉鎖の目安。
  • 8/28 時点の実測：ペナン Minden 159・Seberang Perai 158・Seberang Jaya 154、KL Cheras 160、全国19地点が「不健康」。
  • 見通し：マラヤ大学の気象学者は、風向きが変わる10月の季節風移行期まで改善しにくいとしています。滞在中も続いている可能性が高いです。
  • 症状：目のかゆみ、鼻水、喉の痛み、咳。焦げたような匂いがして、空が乳白色に霞み、太陽がオレンジ色にぼやけます。

対策

  • N95 / KN95 / KF94 マスクを日数分。サージカルマスクや布マスクでは PM2.5 を通してしまいます。
  • 目薬・のど飴・点鼻薬。コンタクトの人は眼鏡も持っていくと楽です。
  • 宿では窓を閉め、エアコンの外気導入をオフに。
  • 毎朝 IQAir か APIMS で数値を確認。API 150 超えの日は屋外の長時間活動を避ける判断を。
  • ペナンの宿は海沿いで景色が売りですが、ヘイズが濃い日は対岸が見えないこともあります。期待値は下げておきましょう。
  • 呼吸器に持病のある人は、普段の薬を多めに。悪化した場合の医療機関は岩永さんに相談を。
屋外メインの予定は、天候ではなく API を見て決めるのが今年のやり方です。 バトゥ洞窟やモスクなど屋外の観光は数値の良い日に寄せ、悪い日は合宿・モール・屋内の飯に振り替えるのが現実的です。

気候・服装

  • 9月は年間通して蒸し暑い。日中30〜33℃、湿度高め。午後にスコールが降ることが多い。
  • 屋内の冷房は強烈。薄手の長袖は必携。
  • 宗教施設では肌の露出を控える（肩・膝を隠す）。

その他

  • 水道水は飲まない。ミネラルウォーターを買う。氷は基本的に市販氷なので大丈夫なことが多いが、体調が不安なら避ける。
  • 左側通行・車優先。横断は慎重に。
  • ペナンもKLも治安は比較的良いですが、スリ・ひったくりは普通にあります。夜のホーカーではスマホと財布から目を離さないこと。
  • コンセントは BF タイプ（英国式3穴）、240V。日本の 100V 機器は「100-240V」表記があるか確認を（スマホ充電器はほぼ対応）。
  • 時差は日本 −1時間（マレーシア GMT+8 / 日本 GMT+9）。
  • 9/6〜9/11 にマレーシアの祝日はありません（Malaysia Day は 9/16）。ETS もフェリーも平日ダイヤで動きます。
