🚢🚆 9/8(火) ペナン → KL の移動

ジョージタウンから フェリー で海峡を渡り、バターワース駅から ETS（電車） でクアラルンプールへ。所要は乗り継ぎ込みで約5時間です。

① フェリー：ジョージタウン → バターワース

  • 区間：Pangkalan Raja Tun Uda（PRTU／ジョージタウン側） → Pangkalan Sultan Abdul Halim（PSAH／バターワース側）
  • 運賃：大人 RM2（約70円）
  • 所要：約20分
  • 運航：バターワース発 6:30〜／ジョージタウン発 〜23:30、30分間隔（平日ラッシュ時は20分間隔）
  • 予約不要（乗車24時間前からのオンライン確保も可）
  • PRTU はジョージタウン中心部・Komtar から徒歩圏。Grab でも数分。
  • バターワース側は屋根付き通路で Butterworth 駅／Penang Sentral に直結、徒歩数分。
券売所は現金不可です。クレジットカードまたは電子ウォレット（Touch 'n Go 等）のみ。 カードが使えるメンバーが立て替える前提で動くと安全。

② ETS：Butterworth → KL Sentral

2026年2月4日改正ダイヤ。所要 約4時間、KL Sentral 直通。

③ チケットの取り方

  • 公式（推奨・最安）：KTMB の KITS オンライン予約 または「KTMB MOBILE」アプリ
  • 代理店：Easybook / BusOnlineTicket（手数料上乗せあり、日本のカードが通りやすい）
  • 発売は乗車30日前から。→ 9/8 分はすでに発売中。
  • 運賃は Flexi Fare（変動制）。上表は目安で、直前ほど高くなります。
  • 駅名の表記は Butterworth → KL Sentral。
最優先の行動項目：7名分の座席をまとめて確保する必要があります。 バラバラの席にならないよう、できるだけ早く（できれば今日中に）公式サイトで押さえましょう。

もし取れなかったら（代替案）

  • Grab / タクシーで直行：ジョージタウン → ペナン大橋経由 → Butterworth 駅（フェリーを省略）。荷物が多い場合はこちらの方がラク。
  • 長距離バス：Penang Sentral → KL（TBS）。所要5〜6時間、RM35〜50程度。本数が多く当日でも取りやすい。
  • 飛行機：PEN → KUL（AirAsia が1日多数）。所要1時間だが空港移動を含めると時間差は小さい。

🍜 グルメ & スポット

食べたいものリスト

ナシレマ（Nasi Lemak）

マレーシアの国民食。ジョージタウンにミシュラン・ビブグルマンの店あり。機内食でも2回出てくるので比べてみるのも一興。

アッサム・ラクサ（Asam Laksa）

ペナン名物の酸っぱ辛い魚介麺。カレーラクサ（スープカレー系）もマスト。

Ayam Goreng Berempah

スパイス衣のフライドチキン。去年もリピート済み。

ホーカー飯

チャークイティオ、ホッケンミー、ロジャ、サテー。夜はここ中心の方針（お酒のある店が限られるため）。

Jalan Alor（KL）

KL の屋台street。Airbnb から近いので夜に。

テタレ / 白コーヒー

甘いミルクティーとイポー式コーヒー。カフェ休憩に。

行きたいところ

  • ジョージタウン（世界遺産） — ストリートアート巡り、アルメニア通り、クー・コンシー
  • Jadi Batek（KL） — バティック染め体験。手軽でお土産にも良い、と岩永さん推薦
  • ブルーモスク / 国立モスク — ※露出NG。羽織ものはレンタル可
  • ペトロナスツインタワー — 夜景。KLCC 公園の噴水ショーも
  • バトゥ洞窟 — カラフルな階段。KL Sentral から電車で30分
  • 中央市場 / Petaling Street — お土産のまとめ買い

具体的な店舗の位置情報・予約済みの店は LINE のノート／アルバムを参照してください。

ℹ️ 現地情報

通信（重要）

  • eSIM 購入済み：Celcom / DiGi、5日間データ無制限。出発前にプロファイルを入れておくと現地で即使えます（アクティベートは現地到着後）。
  • ahamo 勢：海外ローミングがそのまま使える想定（月20GBまで／設定でローミングON）。
  • 電話番号は2つ確保できている状態 → Grab の配車・電話認証はこの2回線で対応。はぐれた時はこの番号に連絡。
  • もし足りなくなったら：ペナン空港／KLIA の到着ロビーにSIMカウンターがあるので、その場で購入できます（パスポート必要）。
  • Airbnb・カフェ・モールは Wi-Fi あり。全員がデータ回線を持つ必要はありません。

お金

  • 通貨：リンギット（RM / MYR）。RM1 ≒ 35円前後（要確認）。
  • 都市部のレストラン・モールはカード可。ホーカー・屋台・小さい店は現金のみ。
  • フェリーの券売所は逆に現金不可（カード／eウォレットのみ）。
  • 両替は空港より市中（ジョージタウンや KL の両替所）の方がレートが良いのが定番。
  • 精算は旅の後にまとめて。立て替えた人はレシート／メモを残しておきましょう。

移動

  • Grab が基本。流しのタクシーより安全・明朗会計。7人なら2台に分乗。
  • KL 市内は LRT / MRT / モノレールが便利。Touch 'n Go カードがあるとスムーズ。
  • KL Sentral ⇄ KLIA は KLIA Ekspres で約33分（RM55前後）。

気候・服装

  • 9月は年間通して蒸し暑い。日中30〜33℃、湿度高め。午後にスコールが降ることが多い。
  • 屋内の冷房は強烈。薄手の長袖は必携。
  • 宗教施設では肌の露出を控える（肩・膝を隠す）。

その他

  • 水道水は飲まない。ミネラルウォーターを買う。氷は基本的に市販氷なので大丈夫なことが多いが、体調が不安なら避ける。
  • 左側通行・車優先。横断は慎重に。
  • コンセントは BF タイプ（英国式3穴）、240V。
  • 時差は日本 −1時間（マレーシア GMT+8 / 日本 GMT+9）。
  • 緊急時：警察・救急 999。在マレーシア日本国大使館（KL）も控えておくと安心。
